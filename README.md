# Character Counter
Proyecto de maquetado web

## Descripción:
Este proyecto consiste en replicar una interfaz moderna de un contador de caracteres en tiempo real. 

## Objetivo:
Practicar:
- Maquetado web con HTML
- Flexbox
- Estilos avanzados con CSS
- Organización de componentes visuales

## Tecnologias utilizadas:
- HTML
- CSS
- Git
- GitHub
